# AlphaLens 0.5.0-beta

The first packaged open-source beta of AlphaLens, an evidence-first US equity research workbench maintained by axlezhao. The project has moved beyond its original competition framing into independent development.

## What this release contains

- Research UI and source/evidence snapshot infrastructure.
- Personal workbench and input-driven portfolio analysis.
- Experimental research-platform control plane.
- English/Chinese project documentation, MIT license, contribution/security policies, templates and automated CI.

## Read before trying it

This is a prerelease, not production-ready investment software. The homepage includes illustrative data. Research jobs currently collect provider snapshots; they do not call an external LLM or generate the displayed thesis. Multi-agent/quality scoring is heuristic. Historical `as_of` metadata does not establish point-in-time correctness.

Database-backed use requires D1 migrations, a trusted authentication integration and scheduled workers. Existing hosted-preview access is unchanged. Paid/authorized provider access is not included; the MIT license applies to project code, not third-party financial data. No automatic trading is implemented.

Workflow lifecycle, isolated self-hosting, real-result rendering and security/integration tests remain priorities. See the [capability inventory](../CAPABILITIES_AND_ROADMAP.md).

## Getting started and validation

Use [the README](../../README.md) for installation and [the development guide](../DEVELOPMENT.md) for runtime boundaries. Use Node.js 24 with pnpm 11.9.0. Run:

```bash
pnpm install --frozen-lockfile
pnpm run lint
pnpm run typecheck
pnpm test
```

These checks cover deterministic helpers, provider contracts and built-worker rendering, not live-provider health, financial performance or an independent security audit. CI results for the release commit are available under [GitHub Actions](https://github.com/axlezhao/AlphaLens/actions/workflows/ci.yml).

Packaging validation on Node.js 24 with pnpm 11.9.0: frozen-lockfile install, lint, type checking, 23 unit tests, production build and 1 rendered-HTML regression passed. No live data-provider, email/WeChat delivery, hosted deployment or multi-user security acceptance was performed for this packaging release.

Existing installations should inspect `drizzle/` and back up their own data before applying migrations. This repository-readiness change does not add a schema migration or deploy a new hosted instance.

Contributions are welcome through [issues](https://github.com/axlezhao/AlphaLens/issues) and pull requests; disclose vulnerabilities privately following [SECURITY.md](../../SECURITY.md).
